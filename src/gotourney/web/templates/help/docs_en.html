    Documentation

    Everything you need to run a tournament with this program – from creating it to the EGD result file. How ratings, pairing and handicap work is explained on the page Tournament system.

    How the program works

    • Browser: the program runs on your computer and is shown in your web browser. Nobody else can reach it; it needs the internet only for the EGD player search.
    • Files: each tournament is a folder with a few files – settings, players, one file per round. These files are the only record: there is no hidden database. Every page reads them fresh, every button writes them.
    • LibreOffice: the player and round files are spreadsheets (.ods). You can open them in LibreOffice Calc at any time, check or change them, save – the browser page updates itself within a few seconds. Browser and LibreOffice are equal: use whatever is more convenient for a step.
    • Next step: the Overview always shows what to do next, with the right buttons.

    Starting and tournaments

    Start the program (GoTournament, or gotourney web on the command line). A small window appears and the browser opens. The window has Open in browser (if you closed the tab), Open tournament folder … and Quit. Closing the window stops the program; all data is already saved.

    • New tournament: on the page Tournaments enter a name, the number of rounds and the language of the printouts. The program creates a folder in Documents/Go tournaments (German: Documents/Go-Turniere); you can choose another folder.
    • Your tournaments lists the tournaments opened recently and all tournaments in that folder.
    • Elsewhere (USB stick, shared folder): use Open tournament folder … in the window, or type the path under Open a tournament.
    • Language: EN / DE at the top right switches the pages. The language of the PDFs is a setting.

    Settings

    The page Settings edits tournament.toml in the tournament folder. Every change is checked before it is saved; if something is wrong, nothing is saved and the problem is explained. Explanations and comments in the file are kept, so you may also edit it in a text editor.

    Tournament

    Name, place (DE, Sampletown), dates, EGD class (A–D) and an EGD comment – these go into the EGD result file. Number of rounds can be changed later, but not below the rounds already paired.

    Rules and time

    Rules: Japanese, Chinese or AGA (or not stated). Choosing them sets the usual komi for even games (Japanese 6.5, Chinese and AGA 7.5); you can change it afterwards. Main time is the thinking time per player in minutes (also in the EGD result file). After the main time:

    nothing (sudden death)Whoever runs out of time loses.
    Byo-yomiA number of periods of a few seconds each, e.g. 5 × 30 seconds. A period is used up only if it runs out before the move is played.
    Canadian byo-yomiA number of stones within a time, e.g. 15 stones in 5 minutes; then the next period starts.
    FischerSeconds added to the clock for every move, optionally with a maximum.

    Rules and time appear on the page Tournament system and on the one-page summary to hang up.

    Printouts

    Language of all PDFs: English, German, French or custom. For custom the texts come from a translation file in the tournament folder (translation.toml, created with a German example).

    Rating, handicap and komi

    k-factorHow fast ratings change (EGD = 1). Default 3.
    Top barMaximum starting rating: a rank like 3d, a number like 2300, or empty for no bar.
    Handicap reduction0 = full handicap, 1 = one stone less, … 9 = always even.
    Handicap floorFor the handicap, lower ratings count as this value (default 20k): two players below it play even. A rank, a GoR number, or empty for no floor. Ratings and pairing are not affected.
    KomiFor even games (6.5, 7 or 7.5) and for handicap games (usually 0.5).

    Pairing

    The random seed fixes all random decisions (colours, joker, ties): the same seed gives the same pairing.

    Pairing rules use a player column – Club, Country, Rank or an additional field – and work in one of four ways:

    RuleEffect
    avoid same valueA pair with the same value counts as if the players were points further apart. Example: Club, 150 points (default).
    prefer same valueA pair with different values counts points further apart. Example: Age group, so children preferably play children.
    never same valueSuch pairs are never made (e.g. members of one family).
    only same valueOnly such pairs are made (e.g. separate groups).

    Values limit a rule to groups: U7, U11, U15 is one group; U7, U11 | U15, U19 are two groups. Players whose value is in no group are not affected.

    Registration and additional player data

    A GoR is marked as possibly outdated if the player's last EGD tournament was more than N years ago, and as doubtful if it differs from the declared rank by more than the tolerance.

    Additional player data are your own columns, e.g. Fee paid or Age group. With values (yes, no) the field is a dropdown; without, it is free text. Only the fields listed here exist: they appear in the registration form, in players.ods and in the standings. Remove a field and it disappears (its column in players.ods stays only if it still contains data). A rule or prize that uses a field must be removed before the field.

    Award ceremony

    Prizes are shown as slides, one per winner, in the order of the list (put the 1st place last for a climax).

    PrizeWho gets it
    placeThe places given, e.g. 3, 2, 1.
    winsEveryone with at least Min. wins wins (e.g. all games won).
    best of a groupThe best Number players whose Column is in the group, e.g. Age group U7, U11, U15 – “best child”. Several groups: one prize per group.
    biggest TGoR gainThe Number players with the biggest gain since the start.

    Empty title = default text in the language of the PDFs. Placeholders in titles: {place} {ordinal} {wins} {games} {group} {n}. Only players without an earlier prize skips players who already got a prize further up the list.

    Registering players

    1. Search the EGD: type part of the name, first and last name in any order (becker a, anna beck) or the EGD PIN. Umlauts can be typed as ue, u or ü. Choose a player with the mouse or the arrow keys and Enter – the form is filled in, with the current GoR from the EGD.
    2. Check rank, GoR and club. Warnings say if the GoR may be outdated or doesn't fit the rank, or if the player is already registered.
    3. Rounds: untick the rounds the player will miss. Joker: tick if the player may sit out when the number of players is odd.
    4. Fill in the additional data and click Add player.
    • Not in the EGD: fill in the form by hand. Name and rank are enough; an empty GoR is taken from the rank.
    • Offline: the EGD player list is stored on your computer and updated once a day, so the search also works at a venue without internet. Update EGD list downloads it now.
    • Change a player: click the name in the list. Remove: only possible as long as the player is in no round; afterwards untick their remaining rounds instead.
    • Check registration lists errors (e.g. missing rank) and warnings before pairing.
    • Everything is stored in players.ods. Each player has a fixed ID, which the round files use.

    Entering players in players.ods by hand

    You can also type players straight into players.ods in LibreOffice – for example from a paper list. Leave the ID empty and type only what you have: an EGD PIN, or a name (surname, ideally also the first name). Round cells left empty mean the player plays; - means not this round.

    The Overview and the Players page then show these rows under Entered by hand with what will become of each:

    • PIN, or a name that matches exactly one EGD player: completed from the EGD – name in EGD spelling, country, club, rank, GoR, EGD PIN.
    • Several EGD players with that name: choose the right one (sorted by their latest tournament).
    • Not in the EGD: registered without EGD data; this needs a rank in the row.

    Complete players gives them an ID and fills in the empty cells. Values you typed (rank, club, rounds, additional data) are kept. Until all rows are completed, the next round cannot be paired, so nobody is left out by mistake.

    Pairing a round

    Pair round 1 pairs all players registered for the round (see how pairing works) and creates round_1.ods. The round page shows the boards. The pairing can be printed in two forms: Pairing (by board) and Pairing (A–Z) (players sorted by surname – easy to find your board). Both PDFs are always created fresh from the round file.

    Changing the pairing before the round starts

    The ⋯ menu next to a board number:

    • Fix board 📌 – the board is kept when you pair again. Release board undoes it.
    • Swap colours, Set handicap (with stones, the weaker player always takes black). Fix the board as well if the change should survive pairing again.
    • Dissolve board – both players become unpaired; Pair again gives them new opponents.

    Pair two players by hand: choose White, Black and optionally the handicap. They get a fixed board; their previous opponents are paired again.

    Pair again replaces all boards that are not fixed – useful after a late cancellation or registration.

    In LibreOffice you can also write a pairing into round_N.ods yourself: player IDs, or just names (Becker, becker a). Names are matched to players and shown for confirmation; mark such boards in the column Finalized so they are kept.

    A round can only be paired when all results of the previous rounds are entered. A game that will not be played is entered as a forfeit.

    During the round

    Start round 1 when the games begin. From now on all boards are fixed; pairing again only pairs latecomers – players registered for the round who are not on a board yet – on new boards at the end (Pair latecomers).

    Entering results

    Enter results: click White wins, Jigo or Black wins on each board. The result is saved at once (“Saved”). More has forfeits – White/Black wins by forfeit, Both lose – and Clear result. Show only missing results and Find a player help in large rounds. A correction is simply another click.

    In LibreOffice the results are marks in round_N.ods:

    ResultWhite winDrawBlack win
    White winsx
    Jigox
    Black winsx
    White wins by forfeitx!
    Both lose (forfeit)!!

    The Handicap and Komi columns may be changed if the players agreed on something else. Check results lists missing or invalid entries.

    When all results are in, the Overview offers the standings and the next round. Correcting a result of an earlier round later is possible: the ratings are recalculated, the pairings of later rounds stay as they are.

    Standings and documents

    The page Standings shows the current table and everything you need at the end:

    • Standings – standings.pdf (to put up: name, rank, TGoR with change, opponents per round) and standings.ods (with all columns, including additional data). Always with the latest results.
    • Wall list – the final places in wall_list.ods. Create it after the last round; you may then correct names in it by hand.
    • EGD result file – the .h9 file made from the wall list. Send it to your national rating officer. A preview of its content is on the page.
    • Tournament system (1 page) – tournament_system.pdf: the rules of this tournament in brief, with its settings, to hang up next to the pairing. Also on the page Tournament system.
    • Award ceremony – awards.pdf, slides in 16:9 with the prize winners. Open it and show it full-screen. Club codes are written out as club names.

    Backups

    Before every pairing and every round start, all tournament files are saved as a zip file in the folder backups (the newest 30 are kept). Create backup now makes one by hand. To go back: close the program, unpack the backup into the tournament folder (replacing the files) and start again.

    Command line

    Everything can also be done with the command gotourney in a terminal (when installed with Python), e.g. gotourney pair 2, gotourney start 2, gotourney standings. Every command has --help and prints the next steps. The full reference is in Guide.pdf (German: Anleitung.pdf), which comes with the program.

    Problems and solutions

    “… is open in LibreOffice”

    Save the file in LibreOffice (keep the .ods format), close it, and click again. If LibreOffice crashed, a lock file .~lock.…# may be left in the folder; delete it.

    “Odd number of players and no joker”

    Mark a player as joker on the Players page (or ask someone to sit out and untick the round for them), then pair again.

    “No complete pairing without rematches is possible”

    Happens in small tournaments in late rounds, or with strict rules. Pair some players by hand, or relax a never/only rule, then pair again.

    A player arrives late

    Register them (or tick the round). Before the start: Pair again. After the start: Pair latecomers: the latecomers are paired among each other, so an odd number of them needs a joker among them.

    A player leaves the tournament

    Untick their remaining rounds on the Players page. If their game in the current round is not played, enter it as a forfeit.

    The settings say “changed elsewhere”

    tournament.toml was changed in the meantime (e.g. in another tab). Reload the page and make your change again.

    The EGD search finds nobody

    The player list could not be downloaded (no internet). Type the data by hand – name and rank are enough – or try Update EGD list later.

    A PDF cannot be created

    Close it in your PDF viewer if it is open, and click again.
